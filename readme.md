# Income Tax Home Page

CSE326 frontend exercise recreating an income-tax e-filing home page, including sample login and news pages. This is an educational static mockup, not a tax-filing service.

## Getting started

Run `python -m http.server 8000` here and open `http://localhost:8000/`. The implementation uses plain HTML and CSS.
